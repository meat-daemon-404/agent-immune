# Contributor Covenant Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
the standard used by tens of thousands of open-source communities.

In short: be respectful, assume good faith, and keep critique aimed at code
and claims — not people. Reports go to the maintainer through
[GitHub contact](https://github.com/meat-daemon-404) or a private security
report; every report is reviewed.
