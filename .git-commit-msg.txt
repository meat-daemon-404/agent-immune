Slash commands execute inside a model Bash call WITHOUT the hook
environment, so the CLI could not see ZCODE_PLUGIN_DATA and resolved to
<project>/.dsh/immune.sqlite - a different, empty file from the one the
hooks write (plugins/data/.../immune.sqlite). Every /immune listing would
have shown nothing.

- hooks extend the self-location marker: line 1 plugin root, line 2 the
  database path actually in use; rewritten on drift so it self-heals
- resolveDbPath consults the marker when the host env is absent
  (explicit override > host plugin data > marker > project .dsh)
- proven end to end: episode learned under the hook env, listed by the
  CLI with the env absent, 47/47 tests
