feat(v1.0): repeat suppression, target-scoped pairing, Jaccard merge, batch distillation, path-affinity rerank

Five modules from the v1.0 task order. Where the spec met reality, the
interpretation is recorded here.

1. Repeat suppression (core/store/turn-state.ts): an identical candidate set
   stays silent for 4 turns and does NOT count a hit - hit_count drives
   promotion and anti-rot, so inflated counts would corrupt the library's own
   statistics. resume/clear/compact reset the state. This supersedes an
   existing assertion ("a later turn may inject again"); the test was updated
   and extended to prove both the suppression and the window expiry.

2. Target-scoped pairing (core/pairing.ts): a success closes an episode only
   for the same kind of work - same file for file tools, same PROGRAM FAMILY
   for commands. The spec's literal "first program + first subcommand" would
   have rejected npm-run-build followed by npx-vite-build, a real and common
   fix; the family rule accepts it while still refusing npm then git.
   Read-only probes (ls/pwd/cat/git status/git log/git diff/which) never close
   an episode.

   Jaccard merge (core/similarity.ts): trigram Jaccard alone scored a genuine
   rewording at 0.545, below the 0.70 threshold, because one inserted CJK
   character shifts every following trigram. The score is now
   max(trigram, character-set) Jaccard: 0.875 for that pair, 0.000 for
   unrelated text. Threshold stays 0.70, and a human correction or model
   rewrite overwrites the stored wording.

3. Batch distillation (core/distiller.ts + prompts.ts): up to 4 episodes per
   request when a model is configured. Every failure path - transport error,
   non-array reply, missing id, invented id - degrades to the deterministic
   rule for the affected episodes, so a bad batch never loses a queued job.
   The prompt states the skip criteria explicitly: transient network, one-off
   typo, sandbox/permission denial, missing binary.

4. Path-affinity rerank (core/store/rerank.ts): retrieval widened to 2x, then
   re-ranked in memory - x1.5 path affinity, x0.85 shared-library discount,
   time decay 1/(1+0.02*days).

5. Docs and probes: README English gains Dashboard, Native UI (dsh.client),
   Sync & Doctor, Guard, the four-layer failure judgement table and the new
   design notes; Layout now says "five verification & benchmark scripts".
   doctor gains a Native UI contract check (dsh.client + exports["./client"] +
   a loader-registered bundle) - its first run caught my own path arithmetic
   (the package root is FOUR levels up, not three).

106 unit tests (17 new in test/v1-features.test.mjs), 79 acceptance assertions.
